The Daily Globe — a one-page newspaper front page summing up the world's news of Tuesday 24 November 2026 in a single 1024x1024 image: Huang is back at Nvidia (shares +31%), COP31 collapses in Antalya, the 2031 and 2035 World Cup hosts are named, a Russian ship is hit by a drone and towed home, a deadly factory fire in Banten, and the World Chess Championship opens in Geneva — plus the day in brief.

`main.py` draws the whole front page with the Python standard library only (no third-party packages, no network, no randomness) and writes `/output/entry.png`. Two runs write byte-identical files.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
